# AmazonAlexaReviewUsingSentimentalAnalysis

THE REPOSITORY CONTAINS THREE PYTHON FILES - MAIN, MODEL, WORKING

THE WORKING.PY FILE HAS THE MODEL WHICH PREDICTS IF THE REVIEW IS POSITIVE OR NEGATIVE. THERE IS NO UI FOR THIS.
YOU CAN RUN THIS FILE USING THE COMMAND "PYTHON WORKING.PY" IN YOUR TERMINAL.

THE MODEL.PY FILE HAS THE SAME MODEL WHICH IS PRESENT IN THE WORKING.PY FILE BUT IN HERE, THE H5 AND PKL FILES ARE GENERATED SO THAT THEY CAN BE USED DIRECTLY IN OTHER CODES WITHOUT TRAINING THE MODEL AGAIN AND AGAIN. SENTIMENT_MODEL1.H5 AND TOKENIZER1.PKL ARE THE OUTPUTS OF THIS FILE.
YOU CAN RUN THIS FILE USING THE COMMAND "PYTHON MAODEL.PY: IN YOU TERMINAL.

THE MAIN.PY FILE IMPORTS THE PRETRAINED MODEL(SEENTIMENT_MODEL1.H5) AND PRETRAINED TOKENIZER(TOKENIZER1.PKL) AND PREDICTS IF THE GIVEN USER REVIEW IS POSITIVE OR NEGATIVE AND IN ADDITION TO THAT A GOOGLE API IS INTEGRATED TO DO DETAILED ANALYSIS ON THE GIVEN REVIEW ADN A PROPER UI IS CREATED USING STREAMLIT.
YOU CAN RUN THIS FILE USING THE COMMANG "STREAMLIT RUN MAIN.PY" IN THE TERMINAL.
